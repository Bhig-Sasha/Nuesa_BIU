Timetable

Paste Bulk Timetable

How to use: Copy rows from your source (Word, Excel, PDF, website) where each row is tab-separated. Supported column orders:
• Date • Code • Title • Time • Venue (exam)
• Date • Code • Title • Time (exam, no venue)
• Day • Code • Title • Time • Venue (class)
• Day • Code • Title • Time • Venue • Lecturer (class, optional lecturer)
Time accepts 9:00 AM–12:00 PM, 9:00-12:00, 09:00–12:00, etc. Date accepts 26 Nov 2026 (Thu), 2026-11-26, 26/11/2026.
Tip: Append "CBT", "written", "practical", or "oral" to any row and it will set that exam's type. For class rows, a final non-venue column is treated as the lecturer name.
