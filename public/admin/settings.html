Session Management Rules
  1. Only one academic session can be active at a time.
  2. New sessions are created as inactive until explicitly activated.
  3. Activating a new session requires confirmation and automatically deactivates the current one.
  4. Previous sessions remain available for historical records — deactivating does not delete.
  5. Session names must be unique (format: YYYY/YYYY).

Activate Session

You are about to activate — as the current academic session.

This will deactivate the currently active session. Historical records will NOT be affected — all previous data remains tied to their original session.

The active session is displayed on the admin dashboard and used as the default for new members, events, and course reps.
